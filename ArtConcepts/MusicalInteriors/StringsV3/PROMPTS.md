# Ventanas con cuerdas

Ediciones mediante herramienta integrada de imágenes. Originales PaletteV2 conservados. Cuerdas verticales en ventanas redondas y de guitarra. Hay muestras con alfa cero entre cuerdas en piano, guitarra y percusión; no implica limpieza completa. Gramófono conserva opacidad residual en los huecos (muestras de alfa desde 24/255): necesita limpieza de transparencia antes de producción. Planchas conceptuales, no tiles recortados o ajustados a grilla.

## 01-piano-interior

Use case: precise-object-edit. Edit the attached existing 12-module interior wall sprite sheet ONLY by adding taut GUITAR STRINGS across the specified round / guitar soundhole window openings. Add six slender evenly spaced VERTICAL parallel strings, subtle graduated thickness, cream/gold with fine burgundy edges, anchored to existing upper and lower window rim. Strings must look like musical strings, not thick prison bars. Keep lots of clear transparent space between strings. Preserve EXACTLY palette, all masonry, carved notes/staffs, frame designs, layout, module count, dimensions, 2D orthographic view and all other windows unchanged. Do not put strings across solid circular ornaments or musical note medallions. Preserve alpha transparency in gutters and window holes, including between strings; output actual transparent RGBA. Hidden brown RGB in source holes is NOT a wall and must stay alpha=0. No new scenery, background, glass, text, added modules or redesign. Row/column count starts at top-left, 1-based. Modify large circular window at row 2 column 3, and the small genuinely open round/oval upper apertures in row 3 columns 2 and 4. Do not change arched windows or solid medallions.
